# Software

## Things I use

- [neovim](https://neovim.io) The best editor i have ever used. Its simple, infinitely customizable and configurable, uses lua (i love lua syntax) and uses barely any ram. 
- [fedora](https://fedoraproject.org/) After using archlinux for a long time, i decided to move on to a stable distro. Check out my [thoughts](/stuff/02-fedora) about my migration.
- [lua](https://www.lua.org/) Ultra-lightweight scripting language designed around associative table that acts as array or dict. In the ideal universe i would be using lua all the time instead of python (soon)
